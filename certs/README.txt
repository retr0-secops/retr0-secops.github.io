CERTIFICATE IMAGES FOR THE BADGE WALL
=====================================

Each badge on the home page shows one image from this folder when flipped.
No code changes are needed. Just swap the files.

HOW TO REPLACE A PLACEHOLDER
  - Save your certificate with the SAME name as the placeholder.
  - .jpg, .jpeg or .png all work.
  - If you upload a .jpg, the site uses it automatically
    (it checks .jpg first, then .jpeg, then .png).
  - Optional: delete the placeholder .png once your real file is in.

FILE NAMES
  01-cap.jpg / .png   ->  Certified AppSec Practitioner (CAP)
  02-ccsp-aws.jpg / .png   ->  Certified Cloud Security Practitioner, AWS
  03-api-security-architect.jpg / .png   ->  API Security Architect
  04-splunk-soc.jpg / .png   ->  Splunk Security Operations and Defense Analyst
  05-android-bug-bounty.jpg / .png   ->  Android Bug Bounty
  06-api-pentesting.jpg / .png   ->  API Penetration Testing
  07-isc2-cc.jpg / .png   ->  ISC2 Certified in Cybersecurity
  08-network-defense.jpg / .png   ->  Network Defense Essentials
  09-digital-forensics.jpg / .png   ->  Digital Forensics Essentials
  10-cybersecurity-business.jpg / .png   ->  CyberSecurity for Businesses
  11-threat-intel.jpg / .png   ->  Threat Intelligence Analyst

TIPS
  - Landscape images look best (around 1200 x 850 px).
  - Keep each file under ~500 KB so the page loads quickly.
  - Names are case-sensitive on GitHub: use lowercase exactly as above.
  - Blur or crop out anything private (certificate IDs you don't want public,
    addresses, dates of birth) before uploading.
